# Security policy

Security fixes target the latest released version, available on the
[Releases page](https://github.com/cupok/yt-ad-skip/releases/latest).
Reports against the current `main` branch are also welcome. Older release lines
do not currently have a separate maintenance commitment.

## Report a vulnerability

Private vulnerability reporting is enabled. On GitHub, use
**Security → Advisories → Report a vulnerability** from the repository's
[Advisories page](https://github.com/cupok/yt-ad-skip/security/advisories).
Include the affected version, reproduction steps, impact, and a minimal example.
Remove unrelated personal information.

Do not publish exploitable details, credentials, or raw diagnostic logs in a
public issue.

Reports are handled by the maintainer on a voluntary basis. There is currently
no response-time guarantee or paid bug bounty.
